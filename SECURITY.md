# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in CaseMesh, please DO NOT open a public GitHub issue.

Please report vulnerabilities privately by emailing the maintainers or filing a GitHub Security Advisory. We will acknowledge receipt within 48 hours and coordinate responsible disclosure.
